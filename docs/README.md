# Documentos

## Conectar-WhatsApp-n8n-IA.pdf

Guía paso a paso para conectar WhatsApp API, n8n y el agente de IA al CRM.

No se edita a mano: sale de `scripts/armar-guia-whatsapp.py`, y se rearma con

    python3 scripts/armar-guia-whatsapp.py

Está escrita contra lo que el CRM tiene construido —el webhook, la API para
automatizaciones y el módulo de Plantillas—, así que si alguno de los tres
cambia, hay que actualizar el script y volver a generarla. Un PDF suelto que
nadie sabe de dónde salió envejece sin que se note.
